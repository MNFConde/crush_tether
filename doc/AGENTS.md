# AGENTS.md（doc/ 写作约束）

> 本文档是 `doc/` 目录的写作约束说明：doc/ 各篇文档的撰写与维护规则在此统一约定，随实现持续更新，供后续会话据此维护文档。

## 文档即源码

- `doc/` 只收与项目架构、设计、实现相关的文档；提交规范、工作流等约束/约定不入 doc/（提交格式放 `.agents/rules/`）；归属拿不准时先确认再放。
- **设计单一事实源 = `design.md`**：同一主题只在 `design.md` 一处详述，不分散到其他文档；其余内容一律以链接回指、不复述。
- 引用一律 markdown 链接（跨文件 `[x](file.md#锚点)` / 站内 `[x](#锚点)`），不用裸编号。
- 改完 doc 必须跑锚点一致性检查，退出码非 0 = 有不匹配（脚本届时建立于 `script/`，参考 mdor 的 `script/check-links.py`）。

## 方案状态标记（doc/ 写作约定）

doc/ 中出现「当前方案 vs 预留备选 vs 被替换」多候选时，用统一标签标记，分行内简记与块记两种格式，标签文字两种格式下必须一字不差：

- **`【当前】`**：当前选择并生效
- **`【备选】`**：预留方案，仅当触发条件成立才实现/替换
- **`【已否决】`**：经论证被否定的替代方案（未实现）
- **`【已替换】`**：曾实现/曾为主案，后被某原因替换

**行内简记 = 链接**：用于表格单元 / 一句话提及。标签 + 方案标题作为链接文本，指向对应块记的小标题锚点：

```markdown
[【当前】 三档分类语义](#三档分类语义)
```

**块记 = 独立小标题 + admonition callout**：用于需要多行展开的方案详情。每个块配一个独立小标题作锚点（标题只写方案名、不含标记，保锚点干净），紧接 callout；callout 类型 ↔ 标签映射：`【当前】`→`[!IMPORTANT]`、`【备选】`→`[!NOTE]`、`【已否决】`→`[!CAUTION]`、`【已替换】`→`[!WARNING]`。

方案状态变化时同步更新标记与触发/原因，避免误导后续会话。

## 文档存档（结构调整/精简前）

- 对 doc/ 做结构重组、精简、整篇重写前，先整体快照：新建 `archive_doc_v{num}/`，`num` = 现有存档最大编号 + 1。
- 快照 = 复制本目录顶层全部文件，**不含任何 `archive_doc_v*` 存档目录**，复制完再在顶层调整。
- 旧存档永不删除；历史归档勿改。
