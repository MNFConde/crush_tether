## script/ 目录约定

- 需要持久化、本地运行的脚本一律放 `script/`，由 uv 管理环境（根 `pyproject.toml`，共享单环境）
- 简单脚本：单文件 `{name}.py`，本身即入口
- 复杂脚本：主体放 `{name}/`（作为包，含 `__init__.py`），入口 `{name}.py` 只做薄封装（import 子包 + 触发）
- 统一触发：`uv run --directory script {name}.py`

## 临时脚本三次法则

约束对象 = 同一功能的分析/验证逻辑反复出现（如 TOML 片段校验、锚点检查）；不约束一次性诊断探针（排障灵活性优先，不立门槛）。

- **判定口径**：功能相同即算重复（参数/目标文件变化不算新脚本）；单行 shell 惯用语不算脚本；同一会话内重写与跨会话重现同等计数
- **第 3 次出现必须固化**：进 `script/`（按上方目录约定）+ [scripts.md](scripts.md) 登记作用/用法；固化后**只准扩展既有脚本**（新 CLI 参数或新函数，登记用法），禁止再为该功能另写临时脚本散落 /tmp 或会话内
- **一次性探针登记义务**：单/双次使用的诊断代码在 [scripts.md](scripts.md)「临时探针台账」记一行（日期/内容/用途/次数）；**跨会话累计 3 次**的探针同样升级固化
- 台账是记忆装置：写探针前先查台账——台账里已有近似条目且自己就是第 3 次，直接固化
